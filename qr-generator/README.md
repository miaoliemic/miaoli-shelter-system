# QR Code 產生器

給社會處在災害發生時印製現場 QR Code 用。單一網頁、不連網路、不連系統，直接用瀏覽器開 `index.html` 就能用（也可以放在 GitHub Pages）。

## 分頁

| 分頁 | 狀態 | 產出 |
|---|---|---|
| ① 開設收容所（簽到 QR） | 第一版 | 每所一張 A4 簽到卡＋CSV（匯入 Notion「收容所開設」） |
| ② 居民號碼牌 | 下一步 | |
| ③ 物資標籤 | 下一步 | |

## ① 開設收容所：使用流程

1. 填災害名稱（例：`2026-10 ○○颱風`）、災害類別、開設時間。
2. 勾選要開設的收容所。依災害類別標出適用的收容所；也可以取消篩選看全部 21 所。
3. 按「產生簽到 QR」：每所產生一組隨機簽到代碼（`SIGN-` 加 5 碼，規則見 [docs/QR編碼規則.md](../docs/QR編碼規則.md)）。
4. 「列印」：一所一張 A4。卡片上不印簽到代碼，避免被誤認為個人專用。
5. 「下載 CSV」，匯入 Notion：
   - 先在「災害事件」建立同名的災害。
   - 打開「收容所開設」→ 右上角 ⋯ → 合併 CSV（Merge with CSV）。
   - 「災害事件」、「收容所」是關聯欄，依名稱連到同名頁面；匯入後請檢查有沒有連上。
   - 開設狀態是「整備中」：匯入後工作人員就能掃 QR 簽到、開始整備。整備完成由所內管理者在本所頁面送出（→ 待核准），社會處核准後改成「開設中」，民眾的「收容所資訊」才會列出這一所。

## 注意

- **QR 要等 CSV 匯入 Notion 後才會生效**：系統要能在「收容所開設」查到這組簽到代碼。
- 這一批的代碼存在瀏覽器（localStorage），重新整理不會變。按「清除這批」才會重新開始；已印出的 QR 不受影響。
- 換一台電腦或清除瀏覽器資料，就看不到之前那一批（代碼仍在 Notion）。
- 收容所資料在 `shelters.js`，只放公開資訊；管理人姓名、電話不放進版本庫。
- QR 函式庫：`vendor/qrcode.js`（qrcode-generator 1.4.4，Kazuhiko Arase，MIT 授權）。
