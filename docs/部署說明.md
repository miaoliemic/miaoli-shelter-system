# 部署說明：在自己的帳號架起這套系統

本系統由三部分組成：Notion（資料庫）、Make.com（自動化）、LINE 官方帳號（現場介面）。照下面的順序在自己的帳號建好，就可以跑起來。

## 1. Notion：建立資料庫

- 依 `docs/第一版LINE流程.md` 和畫布 `系統功能架構.excalidraw`，建立 13 張資料表：災害事件、收容所開設、收容所、收容登記、家戶、號碼牌、工作人員名冊、出勤紀錄、進出紀錄、物資品項、物資異動紀錄、現場日誌、問答與公告。
- 欄位名稱要和藍圖裡用到的**一字不差**，例如「簽到代碼」、「派駐開設」、「在所狀態」。
- 取得 7 張表的 **data source ID**（collection ID）：工作人員名冊、收容所開設、出勤紀錄、現場日誌、號碼牌、收容登記、進出紀錄。

> 待補：資料表欄位的完整清單（可以匯出成範本，之後補上）。

## 2. LINE：官方帳號與 Messaging API

1. 建立 LINE 官方帳號，並在 LINE Developers 開啟 Messaging API。
2. 在 Make.com 建立 LINE 連線，用 channel access token。這個 token 只存在 Make.com，不要放進版本庫。
3. 圖文選單由 Make.com 情境「12」建立，不必在 LINE Official Account Manager 設定（見第 4、5 步）。

## 3. Make.com：連線與 webhook

1. 建立 Notion 連線，並把根頁面分享給它。
2. 建立 LINE「Watch Events」webhook，把 webhook 網址貼到 LINE Developers 的 Webhook URL。
3. 記下 webhook 編號、LINE 連線編號、Notion 連線編號，三個都是數字。

## 4. 填設定、產生藍圖

```bash
cp tools/config.example.json tools/config.local.json
```

- 編輯 `tools/config.local.json`，填入上面拿到的 ID 和編號。
- 選單圖片：建立一個 Notion 頁面，在頁面裡放**第一組左右兩欄**：左欄放一般選單圖、右欄放加乘選單圖。把頁面 ID 填進 `richmenu_page_id`。系統用每一欄裡**最後一張**圖片。
  - 用預設圖：執行 `python tools/make_richmenu.py`，產生 `assets/richmenu_public.png`、`richmenu_staff.png`。
  - 自己設計：執行 `python tools/make_richmenu.py --template`，產生兩張設計範本，照範本設計 2500 × 1686 px 的圖。
  - 換圖：把新圖放進該欄，取代原本那張，再執行一次情境「12」。一般選單會立刻換掉；加乘選單要等工作人員簽退後重新簽到。

```bash
python tools/make_blueprints.py
```

藍圖會輸出在 `make/`。這個資料夾不進版本庫，因為裡面是你的實際 ID。版本庫裡的 `make/example/` 是用範例設定產生的參考版本。

## 5. 匯入 Make.com

1. 在 Make.com 用「Import Blueprint」匯入 `make/12_建立圖文選單.blueprint.json`，執行一次（Run once）。這會建立兩張選單、把一般選單設為預設、設定加乘選單的別名。
2. 匯入 `make/11_LINE訊息_第一版.blueprint.json`，然後啟用。

## 6. 開始使用

1. 工作人員在 LINE 按「工作人員專區」→「申請開通」。
2. 管理者到 Notion 的工作人員名冊設定角色，勾選「啟用中」。
3. 社會處建立災害事件和收容所開設，填好簽到代碼，印出簽到 QR。QR 格式見 `docs/QR編碼規則.md`。
