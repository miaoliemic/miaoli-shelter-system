## 二、Notion 搬家後要更換的設定

Notion 頁面或資料庫搬到另一個工作區後，ID 通常會改變。搬完之後依序處理：

1. **Make.com 的 Notion 連線**：用縣府的 Notion 帳號重新授權。建議改用機器人帳號（Internal integration），並把根頁面分享給它。
2. **資料表 ID**：在 `tools/config.local.json` 的 `notion.data_sources` 更新 7 張表的 data source ID，以及兩個選單圖片頁面 `notion.richmenu_public_page_id`、`notion.richmenu_staff_page_id`。
   實際的 ID 記在本機的 `建置紀錄.md`（不進版本庫）。

3. **連線編號**：在 Make.com 重新建立連線後，更新 `tools/config.local.json` 的 `make` 區塊；webhook 換了也一樣。
4. 執行 `python tools/make_blueprints.py` 重新產生藍圖，再更新到 Make.com 的情境。
5. 其他資料表的 ID（災害事件、收容所等）記錄在本機的 `建置紀錄.md`，儀表板要讀資料時才用得到。

## 三、LINE 圖文選單

- 加乘選單的別名是 `staff-plus`，流程會用別名查出選單 ID，所以**重建選單時不用改程式**，只要把別名指到新選單。
- 兩張選單（一般、加乘）都由 Make.com 情境「12 建立圖文選單（一般＋加乘）」建立。換圖或重建時執行它。
- 圖片放在 Notion「系統素材：LINE 圖文選單」的兩個子頁面，頁面 ID 寫在 `tools/config.local.json`。
